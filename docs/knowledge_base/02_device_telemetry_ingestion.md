# How Device Telemetry Is Ingested Into TORUS

## Source
Device telemetry is synthetically generated by
`data_generators/generate_device_telemetry.py`, simulating multiple
ultrasound devices reporting hourly readings over a 90-day period. Each
reading includes:
- `device_id` — unique identifier for the ultrasound unit
- `timestamp` — the reading's hourly timestamp
- `cpu_utilization` — percentage CPU load
- `memory_utilization` — percentage memory load
- `error_count` — number of errors logged in that interval
- `uptime_flag` — binary flag indicating whether the device was online

## Ingestion path
1. The generator script writes raw telemetry to CSV under `data/raw/`.
2. The Airflow DAG (in `airflow_docker/dags/`) picks up these raw files on
   a schedule and loads them into the PostgreSQL warehouse table
   `fact_device_telemetry`, defined in
   `sql/01_schema_and_raw_tables.sql`.
3. Data quality checks (`sql/04_data_quality_checks.sql`) validate
   completeness and reasonable value ranges before the data is considered
   ready for downstream consumption.
4. The anomaly detection script (`anomaly_detection/detect_anomalies.py`)
   queries `fact_device_telemetry` directly via SQLAlchemy, ordered by
   `device_id, timestamp`.

## Feature engineering on ingestion
Once loaded, `engineer_features()` in `detect_anomalies.py` computes,
per device:
- 6-hour rolling mean and standard deviation of CPU and memory utilization
- Deviation of the current reading from its own rolling mean (captures
  device-relative anomalies rather than comparing across dissimilar
  devices)
- 6-hour rolling sum of error counts

These engineered features feed into the Isolation Forest anomaly model.

## Why device-relative features matter
Different ultrasound devices may have different normal operating
baselines (e.g., an older unit might run hotter under normal conditions).
By using each device's own rolling baseline rather than a global average,
the anomaly detector avoids flagging naturally busier devices as
anomalous just because they differ from the fleet average.
